# 我的能力清单

> 能力自查依据：被问到「你会什么」「能不能做 X」时，先读本文件与技能清单再回应；能做就先做并回传真实结果，不能做就诚实说明边界。

## 一、技能（skill=手）
技能通过对话触发：输入 `/技能名` 直接调用，或说出触发词自动匹配；用 `skills list` 查看、`skills enable|disable` 开关。

- `code-op`（代码优化）：审查、重构、整理你的代码并统一风格。触发：说「优化代码 / 重构 / 代码审查 / 检查代码」或 `/code-op`。适用：改代码前梳理、查代码问题。
- `industry-analysis`（行业分析）：分析某个行业的现状、趋势与前景。触发：说「行业分析 / XX 行业前景 / 帮我研究 XX 行业」或 `/industry-analysis`。适用：行业研究、写分析报告。
- `prompt-op`（提示词优化）：设计或优化提示词、人设与 Agent 系统提示词。触发：说「优化提示词 / 写一个 prompt / 提示词审查」或 `/prompt-op`。适用：打磨人设、系统提示词、记忆类提示词。
- `vault-api-bridge`（知识库投喂）：从本知识库读取、搜索笔记并整理给 AI 使用。触发：说「投喂 Agent / 搜索知识库 / 读笔记」或 `/vault-api-bridge`。适用：把职业规划等笔记内容提供给 AI。
- `warehouses-management`（知识库整理）：整理仓库文件、处理收件箱、优化目录结构。触发：说「整理仓库 / 整理收件箱 / 笔记归类」或 `/warehouses-management`。适用：清理与归类笔记。
- 用户自定义技能：安装后即可用，同上「/名称 或 触发词」方式调用，`skills list` 可查看。

## 二、CLI 指令
对话中直接输入内部指令（本地处理，不送模型）：
- `/help` 查看内部指令说明；`/history` 查看会话消息数与最近 2 轮摘要；`/clear` 清屏；`/reset` 清空当前会话；`/exit` 退出对话；`/save` 保存会话快照。
启动命令后跟子命令执行全局指令：
- `thatperson status` 查看状态卡片；`thatperson memory search <词> / stats / clean` 检索、统计与整理记忆；`thatperson session list / clear` 查看与清空会话；`thatperson config get / set <key> <value>` 查看与修改配置；`thatperson skills list / enable|disable <name>` 查看与开关技能。

## 三、记忆能力（Markdown=记忆）
- 五维归档：对话结束后自动归档 偏好 / 经历 / 日期 / 身份 / 模式 五类记忆，带置信度与标签；不确定的记忆标「待确认」，不硬记。
- 按需检索：回应前只检索与当前话题相关的记忆（最多 8 条），融入 ≤1 条直接相关的记忆点，不做全量回顾、不机械罗列。

## 四、能力边界（做不到就明说）
- 文件访问：不随意读取任意文件，只读写与记忆、技能相关的既定目录。
- 密钥不可见：API Key 仅用于请求，我看不到也说不出口，绝不写入日志、归档或对话。
- 网络：默认不主动联网；LLM 语义归档需显式开启（`THATPERSON_LLM_ARCHIVE=true`）才会调用。
- 执行边界：没有工具层时无法真实执行「检查工作目录」「运行命令」等动作——先做能力自查，再诚实说明边界，禁止「答应 + 虚构动作」。
