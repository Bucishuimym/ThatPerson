# 优秀仓库结构示例

> 角色模型：展示一次完整的「整理仓库」任务应达到的目标形态，以及分类决策如何落地。

## 一、目标仓库结构（树状图）

> 生成树状图时**排除配置与产物目录**：`.obsidian/`、`.claude/`、`.agents/`、`.codex/`、`.git/`、`__pycache__/`、`node_modules/`。

```text
├── 知识库分类指引.md        # 分类规则单一事实源
├── 仓库结构.md              # 最新树状图（每次整理后更新）
│
├── 0-收件箱/                # 临时想法默认存放，定期清理
├── 1-项目/                  # 有截止日期的任务
│   └── 计算器项目/
├── 2-领域/                  # 长期深耕、无明确截止日期
│   └── 个人成长/
├── 3-资源库/                # 已整理成型的知识
│   ├── 01-读书笔记/
│   ├── 02-工具教程/
│   ├── 03-案例分析/
│   ├── 04-知识参考/
│   └── 05-环境清单/
├── 4-存档/                  # 已结束/归档的旧文件
├── 5-卡片盒/                # 原子卡片
│   └── 来源/
├── 6-日记/                  # 每日记录 YYYY-MM-DD.md
├── 7-模板/
├── 8-素材库/                # 图片、附件
└── 9-插件/
```

## 二、分类决策示范

| 笔记 | 决策树判断 | 目标位置 | 补充标签 |
| :--- | :--- | :--- | :--- |
| 《寂寞的游戏》读后感 | 已整理成型的读书笔记 | `3-资源库/01-读书笔记/` | `#类型/读书笔记` `#状态/已完成` |
| Claude CLI 安装教程 | 软件安装类教程 | `3-资源库/02-工具教程/` | `#类型/笔记` `#状态/已完成` |
| "什么是Token" 概念卡 | 单一原子概念 | `5-卡片盒/来源/` | `#类型/卡片` `#状态/待复习` |
| 一个客户需求 | 有截止日期的任务 | `1-项目/客户项目/` | `#类型/项目` `#状态/进行中` |
| 临时收集的文章链接 | 尚未读、待处理 | `0-收件箱/` | `#状态/待整理` |
| 旧的杂乱草稿合集 | 已无使用价值或已完结 | `4-存档/` | `#类型/笔记` `#状态/已归档` |

## 三、整理原则要点

- **只新建文件夹 + 移动文件**；不修改文件内容、不重命名（除非用户明确要求）。
- 批量移动前展示完整移动清单（文件 → 目标位置），经用户确认再执行；检测同名冲突。
- 移动后补/改标签（`#主题/` `#类型/` `#状态/`），把相对链接改写为 wikilink，校验入链不断链。
- 0-9 标准文件夹缺失时自动补建空文件夹，保持结构完整。
- 每次整理输出「整理清单」变更台账，并更新根目录树状图（排除配置/产物目录）。
