## 一、核心摘要

**一句话总结：**
AI智能体行业正处于资本周期"资本过热→局部整合"的剧烈分化期——编码Agent已进入整合阶段、垂直Agent处于资本流入期、情感陪伴Agent刚遭遇监管重锤进入产能出清、Agent基础设施处于资本流入上升期；行业整体供给侧正在从"讲故事"转向"看订单"，只有具备供给侧壁垒（独占数据、合规牌照、分发渠道、安全信任）的企业能在淘汰中幸存。

**关键发现：**
1. 中国企业级AI智能体市场2026年预计449亿元、2029年突破3320亿元（CAGR 107%）；全球agentic AI市场2026年约$108–120亿、2034年$1390–1960亿——行业总量在爆发，但增速掩盖了极端的结构性分化
2. 供给侧信号亮起红灯：2024年新成立超14,000家AI初创，24个月内死亡率40%；种子轮到A轮毕业率仅20%；只有11–14%的企业智能体试点能进入生产——"竞争忽视"正在被市场清算
3. 资本极端集中：2026年Q1四笔超大轮（OpenAI/Anthropic/xAI/Waymo）占全球VC总额65%；AI Agent融资前3笔占44%、前10家占78%；编码Agent前5名吃掉70%+ ARR——赢家通吃的马太效应
4. 2026年7月15日《人工智能拟人化互动服务管理暂行办法》施行，豆包、千问下线智能体功能——情感陪伴Agent赛道的供给侧新增"合规牌照壁垒"，商业模式从"刺激依赖"转向"服务价值"

**核心观点（资本周期视角）：**
AI智能体不是一个行业，而是"基础模型 → Agent应用 → 分发渠道"叠加出的跨层产业。用《Capital Returns》的框架看，**这个行业最本质的特征是：上游基础模型的技术门槛极高且在持续变化，而中游应用层的进入壁垒极低，导致"竞争忽视"与"僵尸企业"风险同时高企**。我们的核心判断是——编码Agent已进入"资本过热→整合"阶段，未来是少数巨头的定价权游戏；垂直行业Agent正处于"资本流入"的甜蜜期，但商业化验证（从PoC到订单）是生死关；情感陪伴Agent刚经历监管重锤，正处于"资本过热→产能出清"的转折点，合规+记忆资产成为新的供给侧壁垒，这恰好是养成式Agent项目最大的机会窗口与风险点；Agent基础设施处于"资本流入"上升期，是最抗周期的"卖铲人"环节。


## 二、行业定义与范围

### 2.1 行业边界
- 本报告涵盖：AI智能体（AI Agent）——能够理解目标、规划任务、调用工具并自主执行的大模型驱动软件实体，覆盖企业生产工具到消费级情感陪伴
- 相关上下游：
  - 上游：基础大模型（OpenAI、Anthropic、DeepSeek、月之暗面）、算力（RunPod）、开源框架/协议（OpenClaw、MCP、A2A）
  - 中游：各类Agent应用（编码、垂直、情感陪伴、通用入口、基础设施）
  - 下游：IDE/办公平台/社交平台等分发渠道 → 终端用户（开发者、企业、消费者）

### 2.2 行业细分（本报告拆解为5个核心子赛道）

## 四、资本周期分析（核心章节）

> 本章是全文核心，运用《Capital Returns》的资本周期框架，从供给侧而非需求侧审视AI智能体的投资价值。

### 4.1 资本周期位置图谱

```
资本周期阶段图谱：

[资本退出/整合] ← → [资本发现] ← → [资本流入] ← → [资本过热] ← → [产能过剩/崩溃]

通用入口Agent（Manus/豆包）：          ●━━━━━━━━━━━━━━━━━ （资本过热→整合开始，大厂接管）
编码Agent（Cursor/Claude Code）：       ●━━━━━━━━━━━━━━━ （资本过热→整合，五强格局初现）
情感陪伴Agent（星野/猫箱/Character）：  ●━━━━━━━━━━━━━━ （资本过热→监管重锤→产能出清）
垂直行业Agent（Sierra/Harvey）：            ●━━━━━━━━━━━━ （资本流入，商业化验证期）
Agent基础设施（身份/安全/编排）：           ●━━━━━━━━━━━━━━ （资本流入上升期，"卖铲人"）
```

### 4.2 各细分赛道供给侧深度分析

#### 赛道一：编码Agent——"资本过热→整合期"，五强通吃

**需求侧**：全球AI编程市场2024年$67亿→2026年$128亿（+36.2%）→2030年$250亿；AI编程代理市场约$47–94亿。

**供给侧**（整合加速）：
- 头部五强（Copilot、Cursor、Claude Code、Devin/Windsurf、OpenAI Codex）占据70%+ ARR份额，100+初创企业被挤压到"抢残羹"境地
- Cursor ARR达$20亿（22个月从$100万做到$20亿），Claude Code年化$25亿，Copilot $11亿——都在$10亿+ ARR量级
- 并购整合：SpaceX $600亿收购Anysphere；Cognition收购Windsurf
- 定价重置：Cursor从$20/月、Copilot $10/月、Claude Code按量/Max档$100–200，Devin从$500降到$20——**价格战苗头已现**
- 中国市场：字节Trae 41.2%份额"一超"，个人版免费，靠生态导流

**资本周期判断**：编码Agent已进入**"资本过热→整合"**阶段。参照《Capital Returns》的经典剧本，这个赛道正在经历"高回报→资本涌入→产能过剩→价格战→整合"。幸存者将是拥有**模型垂直整合（Claude Code毛利率65% vs Cursor仅35%）**和**分发渠道（Copilot的Azure生态）**的玩家。类似ASML的逻辑——最终会走向"少数巨头+自然寡头"。

#### 赛道二：垂直行业Agent——"资本流入期"，从PoC到订单的生死关

**需求侧**：Sierra两年做到$1.5亿ARR，财富50强超四成是客户；客服赛道融资超$24亿。

**供给侧**（资本流入但商业化瓶颈）：
- 垂直Agent占2026年YTD交易的48.3%、资金的54.6%——资本最追捧的方向
- 但**"不缺掌声，缺的是订单"**：只有11–14%的企业智能体试点进入生产；医疗/法律/金融受合规约束仍处早期
- 典型：Sierra（客服，$9.5亿融资估值$150亿）、Harvey（法律）、Uniti（地产$1200万A轮）
- 供给壁垒是**领域数据+合规+行业分发**，比通用Agent厚得多

**资本周期判断**：垂直Agent处于**"资本流入期"**，供给侧仍有容纳新供给的空间，但正在从"概念验证"转向"订单验证"。这个赛道不会出现编码Agent那样的五强垄断，但会出现"每个垂直行业2–3家头部"的格局。对创业者友好度最高。

#### 赛道三：情感陪伴Agent——"资本过热→监管重锤→产能出清"，合规成为新壁垒

**需求侧**：全球AI陪伴市场2024年$282亿（CAGR 31%）；中国AI情感陪伴2024年12.11亿元→2028年595亿元（CAGR 148.74%）；中国陪伴机器人市场796亿(2024)→1100–1400亿(2026)；全球AI陪伴活跃用户超1.2亿，17%深度用户每天用超1小时。

**供给侧**（剧烈震荡）：
- 竞争格局"头部垄断与长尾创新并存"：CR3=52%、CR5=68%；全球前10%产品吃掉89%收入；字节猫箱（DAU日均125分钟）vs MiniMax星野（71分钟）vs Character.AI（91分钟）
- **2026年7月15日监管新规施行**：禁止向未成年人提供虚拟亲密关系、不得过度迎合/诱导情感依赖。豆包（3.45亿月活）、千问（1.66亿月活）7月3日下线智能体功能，腾讯元宝、网易云音乐妙时下线——**头部大厂集体退出**
- 40%创业死亡率；星野/猫箱月下载量暴跌（星野从486万→93万）
- 美国：加州SB 243法案（全美首部AI陪伴专门法律），FTC问询Google/Meta/OpenAI/Character七家公司

**资本周期判断**：情感陪伴Agent正从**"资本过热"**进入**"产能出清/整合"**。参照TMT泡沫的教训，此前大量资本涌入、技术门槛骤降（开源模型）、产品同质化严重，是基于"用户量翻倍"线性外推的资本错配。监管重锤等于给这个赛道加了一道**"合规牌照壁垒"**——这恰恰是好事：把低质玩家清出场，让有记忆资产、合规能力和真实服务价值的玩家活下来。**判断赢家的关键从"谁有大模型"变成"谁有独占的长期记忆数据+合规原生能力+健康变现模式"**。

#### 赛道四：通用入口Agent——"资本过热→整合"，被大模型吞噬

**需求侧**：一站式自主执行任务的想象空间大，但真实付费订单少。

**供给侧**（泡沫警示）：
- 大厂All-in：阿里、腾讯、字节、百度把智能体打成2026年最拥挤战场
- Manus戏剧性辗转：2025年3月爆火→12月Meta $20亿收购→2026年4月发改委首次叫停AI外资并购→7月腾讯牵头中方财团$20亿回购→新加坡独立运营剑指港股IPO
- 朱啸虎判断："90%的Agent会被大模型吃掉"
- 供给壁垒极低（套壳），大模型厂商随时可以免费/低价推出同类功能（CodeParrot、Tune AI、Wuri等已关闭）

**资本周期判断**：通用入口Agent是 **"资本过热"** 的典型，且已开始 **"整合"** ——独立的通用Agent公司几乎不可能与大厂+基础模型厂商竞争。这类公司要么被收购（Manus），要么创始人加入大模型厂（CloudBot创始人进OpenAI）。对创业者，这是 **"雷区"**。

#### 赛道五：Agent基础设施/编排——"资本流入上升期"，最抗周期的卖铲人

**需求侧**：Agent要规模化落地，必须有身份、安全、编排、可观测、沙箱——这是"Agent原生"的刚需。

**供给侧**（资本流入，壁垒高）：
- 基础设施（runtime/沙箱/身份/可观测/安全）占2026 Q1全部投资的20.7%
- 身份与安全是最大主题：Oasis $120M B轮、NewCore $66M、Runta $20M（a16z领投）、Act $60M、JetStream $34M、WorkOS $100M C轮；机器身份数量已是人类的82倍
- 编排：Guild.ai $44M，多模型编排、Agent工作变现
- 供给壁垒=企业信任+安全专业+技术深度，极高

**资本周期判断**：Agent基础设施处于**"资本流入上升期"**，是整条产业链中最抗周期的环节。参照ASML的"卖铲人"逻辑——无论应用层谁死谁活，基础设施都收"过路费"。但门槛极高，不适合个人创业者，适合有安全/平台背景的团队。

### 4.3 关键概念验证

- **竞争忽视（Competition Neglect）**：2024年14,000家AI初创几乎同时看到"AI机会"，但24个月40%死亡率证明——**没有人计算过"当所有人同时涌入时供给会过剩多少"**。这是整个行业最核心的供给侧真相。
- **僵尸企业（Zombie Company）**：政策鼓励+资本充裕让大量低效Agent创业公司"苟活"而非退出。但2026年融资环境恶化正在加速"僵尸出清"——种子轮融资同比降28%、A轮降10%。
- **创造性毁灭（Creative Destruction）**：监管重锤+融资寒冬正在淘汰"套壳"玩家，为真正有壁垒的玩家（记忆资产、合规、垂直数据）腾出空间。这是行业健康的必经之路。

| 中游基础设施 | Oasis、Guild.ai | 中高 | 高 | 资本流入 |
| 下游分发 | 微软、字节 | 高（生态） | 极高 | 成熟期 |

**关键结论**：产业链价值最集中在上游基础模型（技术垄断）+ 下游分发渠道（生态/网络效应）+ 高壁垒中游（垂直整合的编码Agent、基础设施）。**利润最薄、最危险的是低壁垒中游——通用入口和未差异化的情感陪伴应用**。


## 七、竞争格局分析

### 7.1 竞争格局特征
- **集中度**：整体"赢家通吃"。AI Agent融资前3笔占44%、前10家占78%；前10家公司拿走约80%市场收入
- **竞争焦点**：编码/基础设施拼技术+分发；垂直拼领域数据+合规；情感陪伴拼记忆资产+合规+生态
- **大厂降维打击**：字节（豆包/猫箱/Trae）、腾讯（元宝/Manus）、阿里（通义/钉钉）、百度（千帆）——大厂在流量+模型+资本三层碾压
- **跨界并购**：SpaceX买Cursor、ServiceNow买Moveworks、腾讯财团回购Manus、Meta收购Manus失败——并购成为主要退出通道

### 7.2 主要竞争者分析（对养成式Agent项目最有参考价值的3家）

**字节猫箱（情感陪伴，最强对手）**：
- 核心优势：多模态（实时语音/图像/视频通话）+ 抖音式单列Feeds流 + 广告/支付生态
- 主要弱点：受监管新规冲击、月下载从264万→61万
- 战略意图：以猫箱为AI陪伴入口，Anydoor做海外变现
- 资本周期启示：即便字节这样的巨头也在监管下收缩——**合规是所有人平等的天花板**

**MiniMax星野（情感陪伴，国内先行者）**：
- 核心优势：2000万种人设、月卡12元+内购、阿里6亿美元投资（估值$25亿+）
- 主要弱点：月下载从486万→93万、14–18岁未成年用户基本盘受监管冲击、界面/推荐算法落后猫箱
- 资本周期启示：靠"养成/角色定制"起量成功验证需求，但**用户画像过于年轻化=监管风险集中暴露**

**Claude Code（编码Agent，垂直整合标杆）**：
- 核心优势：CLI原生+自有模型垂直整合，毛利率65%，年化$25亿
- 主要弱点：依赖开发者心智，非企业分发主渠道
- 战略意图：以Agent作为Anthropic模型的分发入口
- 资本周期启示：**垂直整合（拥有模型/记忆/数据）是抵御"套壳被吞噬"的最强壁垒**

### 7.3 潜在进入者
- 基础模型厂商（OpenAI、DeepSeek、月之暗面）随时向下做Agent应用
- 传统软件巨头（微软、Salesforce、ServiceNow）通过并购进入
- 大厂离职高管创业（MainFunc估值$12.5亿等）


## 八、行业驱动力与阻碍（资本周期视角）

### 8.1 驱动因素（供给侧）
1. **技术供给外溢**：开源模型+低成本API让"造Agent"边际成本骤降，供给能力爆发
2. **企业预算转向刚需**：客户服务/营销/软件开发渗透率均超50%，Agent从"锦上添花"变"刚需驱动"
3. **政策红利（企业级）**：2026年写入政府工作报告、2027年普及率70%目标，企业级需求被政策放大
4. **监管出清新供给**：情感陪伴监管重锤淘汰低质玩家，为合规原生+记忆资产型产品腾出空间

### 8.2 阻碍/风险因素（供给侧）
1. **竞争忽视的系统性风险**：14,000家新公司、40%死亡率、只有11–14%试点进入生产——整个行业正在为"供给过剩"买单
2. **大模型吞噬风险**：基础模型厂商随时复制应用层功能，套壳型Agent"死无葬身之地"
3. **僵尸企业+融资寒冬**：种子/A轮融资同比大降，无法融资的创业公司将批量死亡
4. **监管与地缘政治**：情感陪伴受国内新规+美国SB 243双重约束；外资并购受限（Manus案）影响退出通道
5. **商业化瓶颈**：Agent工具调用失败率3–15%，"PoC炼狱"导致订单转化率低


## 九、趋势与展望

### 9.1 短期趋势（1-2年）
1. **编码Agent完成洗牌**：五强格局固化，价格战向"成果计费"演进
2. **垂直Agent从PoC到订单**：只有真正跑通生产环境的垂直Agent能融到下一轮
3. **情感陪伴产能出清**：大厂退出+监管新规，幸存者转向适老/适幼/合规健康陪伴
4. **基础设施安全化**：身份/安全/治理成为Agent落地的"标配刚需"

### 9.2 中期趋势（3-5年）
1. **多智能体系统（MAS）成熟**：从"单体对话"到"主Agent调度子Agent团队"
2. **记忆成为Agent核心资产**：长期记忆、人格一致性、跨会话连续性成为差异化关键——OpenClaw等框架验证了"Markdown=记忆"路径
3. **情感陪伴向多模态演进**：从文本→语音+视觉+情感，成为"虚拟社交"入口
4. **商业模式"成果计费"**：从订阅制转向按成果付费，企业采购决策更理性

### 9.3 长期方向（5年以上）
Agent互联网（MCP/A2A协议互联）→ Agent成为软件的基本形态 → 行业终局是"基础模型寡头 + 垂直整合巨头 + 高壁垒细分冠军"的三层结构。**无壁垒的中间层将被上下两层挤压吞没**。


## 十、关注方向建议

| 方向 | 逻辑 | 风险提示 |
| :--- | :--- | :--- |
| 适老/适幼情感陪伴 | 政策明确鼓励；银发市场付费意愿最强（日本LOVOT 3万元/台售1.5万台）；大厂退出留下的空白；合规壁垒保护先行者 | 需软硬件结合；老年人支付能力与习惯待验证；伦理监管趋严 |
| 记忆资产型陪伴Agent | 用户愿为"持续关系"付费；记忆=护城河；监管倒逼从"刺激依赖"转向"服务价值" | 数据隐私/合规红线；记忆资产沉淀周期长；大厂随时进入 |
| 垂直行业Agent（非编码） | 资本最追捧（54.6%资金）；竞争尚不拥挤；垂直数据+合规是厚壁垒 | PoC炼狱；订单周期长；需行业资源 |
| Agent基础设施（安全/身份） | 最抗周期"卖铲人"；身份/安全刚需爆发 | 门槛极高；重企业销售；不适合个人 |
| 工具型国内+情感陪伴海外 | 隔离监管风险（国内合规工具/海外情感陪伴） | 海外版权/合规（SB 243）；文化适配；支付渠道 |

**对养成式Agent项目的针对性建议：**
- **你的养成式情感陪伴Agent正踩在"资本过热→产能出清"的转折点上**——这是最危险的时刻，也是最有机会的时刻。大厂退出给你留出空白，但监管新规是悬顶之剑。
- **必须做三件事**：① 合规原生设计（未成年人保护、防沉迷、极端情绪干预、避免"诱导情感依赖"）；② 把"记忆/关系资产"做成真壁垒（你已在验证OpenClaw式Markdown记忆，方向正确）；③ 商业模式从"情绪时长"转向"服务价值"（情感陪伴的正外部性：独居老人陪伴、特殊人群支持）。
- **别做通用入口Agent**——那是大厂和基础模型厂商的战场（朱啸虎："90%会被大模型吃掉"）。


## 附录

### A. 分析框架说明：Capital Returns 资本周期理论
本报告运用《Capital Returns: Investing Through the Capital Cycle》方法论：
1. 供给侧分析优于需求侧预测——市场规模是"故事"，资本流入/竞争格局/产能变化是"真相"
2. 警惕"竞争忽视"——每个进入者只算自己的增长，不算加总的过剩
3. 关注资本支出信号——扩产/开店/增员通常是回报下降的预警
4. 寻找"成长中的价值"——高壁垒赛道的高增长才有超额回报
5. 警惕政策阻碍"创造性毁灭"——过度保护低效企业导致"僵尸化"
