## 一、核心摘要

**一句话总结：**
IT计算机行业正处于AI驱动的"世纪级资本豪赌"之中——资本正以史无前例的速度从"人力预算"流向"算力支出"（2026年全球IT支出6.3万亿美元、四大巨头单年资本开支近7000亿美元），但投入产出开始倒挂（每赚1美元要花1.57美元投资），行业从"总量增长"转向"多速分化"：AI算力处于资本过热期、软件SaaS陷入"SaaSpocalypse"式产能出清、消费电子总量承压但AI终端结构性升级、信创在政策硬约束下确定性放量。

**关键发现：**
1. 2026年全球IT支出预计6.31–6.37万亿美元（+13.5%~14.2%），其中数据中心系统支出7879.9亿美元、增速55.8%居首——AI基础设施是"人类历史上最大规模的基础设施项目"
2. 供给侧最刺眼的信号是"资本剪刀差"：四大云巨头2026年资本开支合计近7000亿美元（较2025年+60%），但五大科技巨头到2027年资本开支将首次超过自由现金流——每新增1美元经营现金流要花1.57美元投资，AI投资把巨头拖入"囚徒困境"
3. 软件SaaS遭遇"SaaSpocalypse"：公开市场估值倍数从2021年的16–18倍跌至2026年的6.7倍（-60%），Airtable以较峰值低80%的价格被收购，传统SaaS IPO"暂时死亡"，AI成为估值唯一分水岭（AI原生平台14–18倍 vs 无AI战略5.5–7倍）
4. 信创产业在2027年底国央企100%替代的硬约束下进入订单爆发期：2026年市场2.66万亿（+26.82%），中标金额激增78%，但CPU国产化率仅1–2%——"空间巨大"与"进度紧迫"并存

**核心观点（资本周期视角）：**
IT计算机行业不是单一周期，而是**多个资本周期叠加**的复杂体。用《Capital Returns》的框架看，最关键的供给侧真相是：**资本正在用"裁员+举债"的方式，从传统IT业务"抽血"注入AI基础设施**——美国科技巨头年内裁员近14万人的同时，把数千亿美元砸向数据中心。这种"人机剪刀差"是本轮周期最本质的特征。我们的核心判断是——**AI算力处于"资本过热期"**（需求真实但投入产出倒挂，一旦AI商业化慢于预期将出现严重产能过剩）；**软件SaaS处于"产能出清→整合期"**（AI正在摧毁传统SaaS的经常性收入基础，这是创造性毁灭的典型）；**云计算处于"资本流入→过热过渡"**（IaaS见顶、AI智算接棒但价格战苗头已现）；**信创处于"资本流入期"**（政策硬约束驱动的确定性增长，但需警惕竞争加剧吞噬毛利）；**消费电子处于"成熟期"**（总量下滑，AI终端提供结构性升级）。对个人开发者而言，**最值得关注的是AI应用层和端侧AI（AI PC/手机/眼镜）**——那才是算法工程师和"一人公司"的增量空间，而不是被巨头资本开支绑架的算力军备竞赛。

## 三、宏观环境分析（PEST）

| 维度 | 现状与趋势 | 对行业的影响 |
| :--- | :--- | :--- |
| 政策 (Political) | 2026年"支持公共云发展"首入政府工作报告；"东数西算"八大枢纽推进；算力网首次纳入国家"六张网"（投资超7万亿）；2027年底国央企信创100%替代 | [+] 信创/算力/云受政策强力驱动；[-] 高端AI芯片出口管制加剧国产替代压力 |
| 经济 (Economic) | 全球IT支出6.3万亿美元（+14%）；中国云计算市场2025年1.07万亿（+29%）；但五大巨头资本开支2027年将超自由现金流 | [+] IT投资总量高增长；[-] 投入产出倒挂、融资环境恶化、企业预算承压 |
| 社会 (Social) | 美国科技巨头年内裁员近14万人（"为AI腾资金"）；AI原生公司（OpenAI/Anthropic）反而扩招；"一人公司"（OPC）爆发 | [-] 传统IT岗位重构、职业焦虑；[+] AI原生就业增长、个体开发者兴起 |
| 技术 (Technological) | AI基础设施成为"人类史上最大基建项目"；HBM/CoWoS先进封装紧缺；AI PC/手机/眼镜爆发；Agent重塑软件形态 | [+] 技术供给创造巨大增量；[-] 存储涨价挤压终端、非AI技术被系统性虹吸 |

**关键结论**：宏观环境对行业整体强烈有利（政策+技术+资本三重共振），但**增长高度集中在AI相关环节**，传统IT（消费电子、传统SaaS、非AI半导体）正被系统性虹吸资源。政策是信创的最大确定性，资本是AI算力的最大助推力，也是最大隐患。


## 四、资本周期分析（核心章节）

> 本章是全文核心，运用《Capital Returns》的资本周期框架，从供给侧而非需求侧审视IT计算机行业的投资价值。

### 4.1 资本周期位置图谱

```
资本周期阶段图谱：

[资本退出/整合] ← → [资本发现] ← → [资本流入] ← → [资本过热] ← → [产能过剩/崩溃]

信创/国产替代：      ●━━━━━━━━━━━━━━ （资本发现→流入，政策硬约束驱动）
云计算/数据中心：        ●━━━━━━━━━━━━ （资本流入→过热，AI智算接棒，价格战苗头）
AI算力/半导体：           ●━━━━━━━━━━━━ （资本过热，世纪级capex豪赌，现金流倒挂）
消费电子/终端：                ●━━━━━━━━━━━ （成熟期，总量承压，AI终端结构性升级）
软件/SaaS：                    ●━━━━━━━━━━━ （产能过剩→整合，SaaSpocalypse）
```

### 4.2 各细分赛道供给侧深度分析

#### 赛道一：AI算力/半导体——"资本过热期"，世纪级豪赌

**需求侧**：全球AI算力芯片市场2026年预计超4665亿美元（NVIDIA市占率76.1%）；海外云厂商2026年资本开支合计7164亿美元（+90%），四大云厂商Q1资本开支同比+95%；中国BAT 2025年资本开支2208亿元（+44%）。AI半导体TAM从2025年2350亿美元增至2030年7530亿美元（CAGR 38%）。

**供给侧**（过热信号集中）：
- 台积电2026年资本开支上调至560–600亿美元，全力投向3nm/2nm与CoWoS先进封装；CoWoS产能从2023年底1.3万片/月扩至2027年底16.5–20万片/月，但**月度产能缺口仍维持15–20%**——供给追不上需求
- 存储结构性紧缺：HBM供不应求延续至2027Q2，2026年需求飙至320亿Gb；高带宽内存涨价推高终端成本
- **现金流倒挂是最刺眼的过热信号**：甲骨文2026财年资本开支557亿美元 vs 经营现金流320亿美元（比率从47%飙至174%），2027财年指引900–950亿美元（近现金流的3倍），被迫债权+股权融资500亿美元，股价从高点暴跌65%，标普将其信用评级下调至仅比垃圾级高一档；Alphabet 2026Q2自由现金流转负（-59亿美元，几十年来首次）
- 中国路线差异化突围：国产AI芯片推理TCO比英伟达低30–60%，华为昇腾占国内62–63%份额；大摩判断2030年中国AI GPU市场670亿美元、自给率76%

**资本周期判断**：AI算力处于**"资本过热期"**。这是"为AI建造人类历史上最大基础设施"的狂热——需求真实存在，但每家巨头都在同步扩产，资本支出即将超越现金流。参照《Capital Returns》中"高回报→资本涌入→产能扩张→过剩"的经典剧本，**风险在于AI应用商业化一旦慢于预期，海量数据中心将变成过剩产能**。当前的最大赢家是"卖铲人"（台积电、CoWoS、HBM、先进封装），它们无论下游谁死谁活都收"过路费"。

#### 赛道二：云计算/数据中心——"资本流入→过热过渡"，B端见顶、AI接棒

**需求侧**：中国云计算市场2025年1.07万亿元（+29%）；PaaS增速高达67%（AI平台驱动），IaaS增速从36%回落至24%；公有云占企业级IT市场44.2%；混合云2025年首破千亿（1451.7亿元）。2025年中国AI云市场567亿元。

**供给侧**（竞争加剧）：
- **B端新客户增量见顶**，厂商进入存量争夺战：火山引擎、腾讯云给出"五折甚至更低"营销噱头引流；有头部云厂商内部启动对标火山引擎的"灭火行动"
- 运营商云快速崛起（增速38.9%，高于行业12.7个百分点），与互联网云厂商边界模糊
- 竞争焦点从"有没有云"转向"云能否支撑AI"——智算基础设施、模型部署、数据治理、智能化运维
- 头部集中：阿里云中国IaaS份额32.8%（+2.7pct），AI云市场阿里38.1%、火山引擎20.4%、前五合计超80%
- 华为云2025年主动收缩边缘非核心业务（停售38项服务），聚焦"3+2+1"核心业务——行业从"广撒网"转向"All-in AI"

**资本周期判断**：云计算处于**"资本流入→过热过渡"**阶段。IaaS基础层接近成熟（增速回落、价格战苗头），AI智算/PaaS/MaaS带来二次增长曲线，但**存量竞争+价格战正在压缩利润率**。参照资本周期逻辑，这个赛道的"产能"（数据中心、云节点）正以远超需求的速度扩张，未来2–3年可能出现局部产能过剩。国资云/主权云是政策驱动的例外增长点。

#### 赛道三：软件/SaaS——"产能过剩→整合期"，SaaSpocalypse

**需求侧**：全球软件支出2026年1.44万亿美元（+15.1%，超预期）；生成式AI模型支出增速80.8%；中国软件市场2024–2028年CAGR约13.9%。

**供给侧**（剧烈出清）：
- **估值崩塌**：公开市场SaaS中位EV/Revenue从2021年16–18倍跌至2026年6.7倍（-60%，另一口径3.4倍）；私募较公开市场折价30–40%
- **"SaaSpocalypse"（SaaS末日风暴）**：AI编程代理（Claude Code、OpenAI Codex等）正在侵蚀SaaS的经常性收入基础——企业发现自己能用AI自建原先要订阅的软件
- 标志性案例：Airtable被Bending Spoons以22.5亿美元股权价值收购，较2021年117亿美元峰值暴跌80%；Salesforce自2024年底市值蒸发逾四成；HubSpot单日暴跌19%、Datadog跌19%
- **传统SaaS IPO"暂时死亡"**：2026年上半年86%私募资金流入AI公司，压缩传统SaaS生存空间；PE债务融资收购成为第三条主要退出通道（Thoma Bravo 123亿美元私有化Dayforce）
- 分化：AI原生平台享14–18倍（溢价80–100%），无AI战略仅5.5–7倍；Atlassian（AI转型）单日暴涨35%、Twilio涨20%——**AI是估值唯一分水岭**
- 2025年SaaS并购史上最活跃（2698笔），68%技术领导者计划2026年整合供应商

**资本周期判断**：软件/SaaS处于**"产能过剩→整合期"**，是IT行业资本周期位置最靠后的赛道。这是**创造性毁灭**的典型现场——AI正在摧毁"卖软件许可"的旧商业模式，同时催生"AI原生应用"的新范式。参照《Capital Returns》，这个赛道的整合尚未完成，**大量背负2021年高估值的SaaS独角兽将面临"以50美分买1美元"式的清算**。真正的赢家是深度嵌入工作流、拥有数据所有权、能证明AI价值的企业。

#### 赛道四：消费电子/终端——"成熟期"，总量承压、AI结构性升级

**需求侧**：2026年全球PC出货量预计-11.3%（但收入+1.6%，ASP上涨）；智能手机出货量预计-12.9%（约11亿部，近十年最大跌幅）；存储涨价导致单台PC硬件成本上涨最高2000元。

**供给侧**（结构性分化）：
- **存储短缺挤压**：AI数据中心建设潮使存储大厂将产能转向高利润HBM，DRAM/NAND价格飙升，主流PC存储物料成本2025Q1至2026Q2累计上涨122–237美元
- 引发"降配"趋势，价格敏感用户延长换机周期或转向二手市场
- **AI终端逆势增长**：AI PC渗透率2026年预计24%（出货1.43亿台）；生成式AI手机占比从36%升至45%；AI眼镜2026年突破千万级、2028年2600万台
- **份额向头部集中**：大OEM凭采购能力拿到存储配额，中小厂商被迫减配/提价/退出市场
- 价值向少数环节集中：存储（刚性升级）、散热/热管理（本地推理负载）、结构件

**资本周期判断**：消费电子处于**"成熟期→局部过剩"**。总量需求疲软（换机周期延长、存储涨价压制），但AI终端提供了结构性升级的"第二增长曲线"。参照资本周期框架，这是一个"传统产能出清、新产能（AI终端）培育"的转型期——**短期看是AI给硬件带来溢价，长期看价值将集中在有技术壁垒的环节（存储、散热）和有品牌/生态的头部厂商**。

#### 赛道五：信创/国产替代——"资本发现→流入期"，政策硬约束下的确定性增长

**需求侧**：2026年信创产业市场2.66万亿元（+26.82%）；信创中标金额突破1200亿元（+78%）；工信部2026Q1信创政府采购中标+65%；省级以上政务云信创适配完成率92.3%。

**供给侧**（政策驱动的放量）：
- **2027年底国央企100%信创替代是硬约束**，2026年必须是招标和交付最高峰：工商银行30亿服务器大单、建设银行44亿、兴业银行10亿
- **国产化率仍处低位=巨大空间**：CPU国产化率仅1–2%、存储<5%、操作系统4–5%、中间件8%、数据库47%——替代从硬件层向软件层铺开
- 国产芯片在中国AI服务器占比2026年预计接近80%（TrendForce），英伟达份额从34%骤降至21%
- CPU三路线分化：龙芯（LoongArch，涉密/军工）、飞腾（ARM，政务）、海光（x86兼容，金融商用）
- 服务器整机集中度高：浪潮31.3%、超聚变12.7%、新华三12.5%、联想10.7%（前三56.5%）
- 竞争已从"能不能替代"（及格赛）转向"替代之后能不能更好"（加分赛）——拼生态适配广度、场景落地成熟度、AI融合差异化

**资本周期判断**：信创处于**"资本发现→流入期"**，是IT行业少数由**政策周期**而非市场周期主导的赛道。资本正确定性流入（订单放量、政策加码），但**风险在于：一旦2027年替代目标完成后政策红利退坡，依赖政策的产能可能过剩**；同时资本关注度提升导致参与者快速增加，价格压力和毛利率承压是中期隐患。参照资本周期逻辑，信创的壁垒是"牌照+生态+政策"三重叠加——高壁垒保护先行者，但政策依赖度极高。

### 4.3 关键概念验证

- **竞争忽视（Competition Neglect）**：四大云巨头同时把资本开支翻倍投向数据中心，每家都看到了AI需求的确定性，但**没有人认真计算"当所有人同步扩产时，2027–2028年算力会过剩多少"**。甲骨文被迫举债500亿美元、Alphabet自由现金流转负——这就是"所有人同时看到机会"的代价。
- **创造性毁灭（Creative Destruction）**：SaaSpocalypse是当前最鲜活的案例——AI编程Agent正在摧毁传统SaaS的经常性收入，HubSpot、Salesforce、Datadog暴跌，同时催生AI原生平台（Atlassian暴涨35%）。裁员14万人"为AI腾资金"是毁灭的另一面。
- **僵尸企业（Zombie Company）**：两类僵尸风险——①靠PE债务融资续命的高估值SaaS独角兽（债务杠杆正在挑战偿债能力，NRR从120%+跌至80%）；②信创中依赖政策订单、缺乏真实竞争力的参与者（2027年后可能暴露）。
- **资本剪刀差（"人机"转向）**：这是2026年IT行业最独特的供给侧信号——钱没有消失，只是从工资单（payroll）流向资本支出（capex）。硅谷公司延续半个世纪"人力为核心"的组织形态正在被改写，资本周期从"人力扩张"转向"机器扩张"。

## 七、竞争格局分析

### 7.1 竞争格局特征
- **AI主导的"多速分化"**：AI相关环节（算力、云、信创、AI终端）增长，非AI环节（传统SaaS、消费电子）承压
- **资本开支竞赛**：四大云巨头（Amazon ~2000亿、Alphabet 1750–1850亿、Meta 1150–1350亿、Microsoft ~1450亿美元/年）——竞争焦点从"市场份额"转向"谁拥有更多算力"
- **裁员与扩招并存**：传统巨头裁员14万"为AI腾资金"，AI原生公司（OpenAI、Anthropic）扩招
- **信创"生态为王"**：竞争从产品之争转向生态之争（华为"鲲鹏+昇腾+欧拉+鸿蒙"、中国电子"PKS"）
- **云厂商价格战苗头**：火山引擎/腾讯云"五折"引流，存量争夺白热化

### 7.2 主要竞争者分析（代表性企业）

**台积电（AI算力基础设施霸主）**：
- 核心优势：先进制程+先进封装双龙头，AI芯片收入2024–2029年CAGR 60%
- 主要弱点：资本开支庞大（560–600亿美元/年）、地缘政治风险
- 近期动态：2026年资本开支上调至接近560亿美元上限，CoWoS产能2027年扩至16.5–20万片/月
- 战略意图：锁定AI算力"卖铲人"地位，无论下游谁赢都受益
- **资本周期启示**：技术壁垒持续升高的"ASML式"企业——但要注意其自身资本开支也处于周期顶部

**NVIDIA（AI芯片龙头）**：
- 核心优势：GPU市占率76.1%，生态（CUDA）护城河
- 主要弱点：供给从"一家通吃"转向"GPU+ASIC+中国本土芯片"三轨并行；先进封装/存储产能受制
- 近期动态：2025年取代苹果成为台积电第一大客户；H200定位为中国市场过渡产品
- 战略意图：转型机柜级方案（系统化），从卖芯片到卖算力系统
- **资本周期启示**：处于过热周期顶部的明星企业——需求真实但估值包含高度乐观预期

**阿里云（中国云龙头）**：
- 核心优势：中国IaaS份额32.8%（+2.7pct）、AI云38.1%居首、生态绑定
- 主要弱点：B端增量见顶、价格战压力、资本开支竞争
- 近期动态：AI云市场领跑，通义千问+Agent生态
- 战略意图：从"云计算"转向"AI算力+Agent平台"
- **资本周期启示**：头部集中度提升，但行业整体进入存量竞争，利润率承压

**华为（信创+国产算力核心）**：
- 核心优势：全栈生态（鲲鹏+昇腾+欧拉+鸿蒙）、昇腾占国产AI芯片62–63%
- 主要弱点：高端制程受限（依赖中芯国际）、生态仍需时间
- 近期动态：提出"韬定律"（系统协同设计提升芯片效能），国产算力从"可用"到"好用"
- 战略意图：构建国产算力"根技术"生态
- **资本周期启示**：政策驱动的确定性受益者，但商业化可持续性仍待验证

### 7.3 潜在进入者
- 大模型厂商（OpenAI、Anthropic、DeepSeek）向下游做Agent/软件，重构SaaS
- 运营商云（三大运营商）从网络层切入云市场（+38.9%）
- AI原生创业公司（编程Agent、垂直Agent）侵蚀传统软件市场

**关键结论**：竞争格局的核心特征是**"AI重构一切"**——无论云、软件、终端还是半导体，竞争焦点都被AI重写。传统玩家要么All-in AI（华为云收缩聚焦、阿里云转向智算），要么被创造性毁灭（传统SaaS暴跌）。


## 八、行业驱动力与阻碍（资本周期视角）

### 8.1 驱动因素（供给侧）
1. **AI资本开支的确定性扩张**：四大云巨头2026年资本开支近7000亿美元（+60%），是IT支出增长的最大引擎——资本本身在创造供给和需求
2. **政策三重驱动**：信创2027硬约束（订单爆发）、算力网入国家"六张网"（投资超7万亿）、公共云首入政府工作报告——政策为确定性兜底
3. **国产替代的技术跨越**：国产AI芯片推理TCO比英伟达低30–60%，DeepSeek V4首次用国产算力训练——从"政策驱动"走向"产业自证"
4. **AI终端创造新需求**：AI PC（渗透率24%）、AI手机（45%）、AI眼镜（千万级）——在总量下滑中开辟结构性增量

### 8.2 阻碍/风险因素（供给侧）
1. **投入产出倒挂（最大风险）**：五大科技巨头2027年资本开支将首次超过自由现金流；甲骨文资本开支是经营现金流3倍、被迫举债500亿、评级下调——**如果AI应用商业化慢于预期，海量算力产能将过剩**
2. **"竞争忽视"的产能风险**：所有巨头同步扩产数据中心，2027–2028年可能出现算力过剩+价格战（云已现"五折"苗头）
3. **传统IT的虹吸效应**：非AI半导体（消费/汽车/工控）被AI系统性虹吸资源，复苏弱于预期；传统SaaS被编程Agent侵蚀
4. **信创政策退坡风险**：2027年替代目标完成后政策红利可能减弱，依赖政策的产能将暴露
5. **地缘政治与供应链**：高端AI芯片出口管制、先进封装/存储双短缺、全球政策波动


## 九、趋势与展望

### 9.1 短期趋势（1-2年）
1. **AI算力军备竞赛持续但现金流恶化**：巨头继续加码capex（甲骨文2027指引900–950亿），但债务与信用压力上升，市场开始用"算力/GPU保有量"而非"员工数"估值
2. **SaaS整合加速**：2026–2027年将有更多Airtable式的"高估值独角兽被折价收购"，PE私有化成为主要退出通道
3. **信创进入交付最高峰**：2026–2027年招标与交付集中释放，国产替代从硬件层向软件层全面铺开
4. **AI终端换机潮启动**：AI PC/手机/眼镜带动新一轮换机，但被存储涨价部分抑制

### 9.2 中期趋势（3-5年）
1. **算力供给过剩风险出清**：2027–2028年可能经历一轮"算力泡沫"局部破裂，落后产能被淘汰，行业整合
2. **AI原生软件取代传统SaaS**：编程Agent、垂直Agent、AI工作流成为企业软件主流，软件商业模式从"订阅"转向"成果计费"
3. **云市场进入"AI云"时代**：智算、模型部署、Agent平台成为云厂商核心竞争点，运营商云与互联网云边界进一步模糊
4. **端侧AI成熟**：AI手机/AI眼镜成为"随身Agent"载体，情感陪伴等应用获得新的硬件分发渠道

### 9.3 长期方向（5年以上）
IT行业将完成从"人驱动"到"AI驱动"的范式转移——算力成为新的"电力"基础设施，AI Agent成为新的"劳动力"形态。行业终局是：**AI算力寡头（台积电/英伟达式）+ 云平台巨头（阿里/华为式）+ 高壁垒应用冠军（垂直Agent/AI原生SaaS）**。个人开发者和小公司的机会在**AI应用层和端侧**，而不是被巨头资本开支绑架的算力层。


## 十、关注方向建议

| 方向 | 逻辑 | 风险提示 |
| :--- | :--- | :--- |
| AI应用层（Agent/SaaS重构） | 传统SaaS被创造性毁灭，AI原生应用是增量空间；编程Agent已验证商业模式 | 大模型厂商降维打击；竞争激烈；需要垂直壁垒 |
| 端侧AI（AI PC/手机/眼镜） | AI终端渗透率快速提升（AI手机45%），是Agent的分发载体 | 存储涨价挤压利润；换机周期长；巨头主导 |
| 信创软件层（数据库/中间件/办公） | 国产化率仍低（数据库47%已较好，中间件8%空间大）；2027年前订单确定 | 2027年后政策退坡；竞争加剧毛利承压 |
| 云AI智算（PaaS/MaaS） | PaaS增速67%、AI云567亿元，是云市场第二曲线 | 价格战苗头；巨头资本开支竞争；B端增量见顶 |
| AI算力（回避为主） | 需求真实但已过热，现金流倒挂是核心警示 | 周期性风险极大；估值包含乐观预期；不适合个人 |

**对个人开发者/学习者的针对性建议：**
- **你的AI Agent方向正踩在行业最确定的增量上**——IT行业正在从"卖软件"转向"卖Agent"，而AI应用层（尤其垂直、有记忆、合规的Agent）是巨头算力军备竞赛之外留给个体最大的空间。这与你的情感陪伴Agent项目完全一致。
- **端侧AI是你的长期分发机会**：AI手机（45%渗透）和AI眼镜正在成为"随身Agent"载体，情感陪伴Agent未来可能从App形态走向端侧原生。
- **警惕被"算力叙事"绑架**：巨头用裁员+举债换算力，是资本过热期的典型动作。作为个体，不要试图参与算力军备竞赛，而是站在**应用层收割算力基础设施化的红利**——就像淘金热里卖铲子不如用铲子挖到金子的位置判断，对个体而言应用层就是"更容易挖到金子的地方"。
- **信创是你的"国产算力环境"利好**：你用的DeepSeek正是国产算力从政策驱动走向产业自证的标志（DeepSeek V4首次用国产算力训练）——国产Agent开发环境正在成熟。

### A. 分析框架说明：Capital Returns 资本周期理论
本报告运用《Capital Returns: Investing Through the Capital Cycle》方法论：
1. 供给侧分析优于需求侧预测——市场规模是"故事"，资本流入/竞争格局/产能变化是"真相"
2. 警惕"竞争忽视"——每个进入者只算自己的增长，不算加总的过剩（四大云巨头同步扩产即典型案例）
3. 关注资本支出信号——扩产/增员通常是回报下降的预警（资本开支超自由现金流是强信号）
4. 寻找"成长中的价值"——高壁垒赛道的高增长才有超额回报（信创、AI应用）
5. 警惕政策阻碍"创造性毁灭"——过度保护低效企业导致"僵尸化"

- **资本周期**：高回报→资本流入→产能扩张→竞争加剧→回报下降→资本退出→整合→回报恢复
- **SaaSpocalypse（SaaS末日风暴）**：AI编程代理侵蚀传统SaaS经常性收入基础，导致SaaS估值崩塌和行业出清
- **资本剪刀差**：科技巨头资本开支暴增、人力开支收缩的结构性转向（"人机剪刀差"）
- **CoWoS**：台积电的先进封装技术，AI芯片（如英伟达B200）的关键瓶颈
- **HBM**：高带宽内存，AI芯片的核心存储，2026年供不应求至2027年
- **信创**：信息技术应用创新产业，国产替代的核心载体（2027年底国央企100%替代）
- **OPC（一人公司）**：One-Person Company，AI时代兴起的小型化创业主体
- **NRR**：净收入留存率，SaaS健康度核心指标（从120%+跌至80%预示债务压力）
