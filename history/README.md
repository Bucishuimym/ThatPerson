# history/ 记忆目录说明

本目录由真实对话归档自动产生；预设与示例永不直接写入，演示/测试数据一律使用独立根目录（createMemoryStore(demoRoot)），跑完即弃。

- `profile/`  身份画像：identity.md / preferences.md / traits.md
- `timeline/` 人生节点：milestones.md / important_dates.md
- `experiences/` 经历日志：journal.md
- `insights/` 模式洞察：patterns.md
- `session_logs/` 每日对话摘要：YYYY-MM-DD.md

各分区文件由代码按 4.2 归档格式自动写入，无数据时保持为空（白纸）。
