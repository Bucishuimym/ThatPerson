## 一、执行过程（git 命令清单）

1. `git status --short --branch` —— 查看工作区与暂存区状态（当时仓库尚无任何 commit，且部分文件已被误暂存）。
2. `git diff --cached --stat` / `git diff --stat` —— 核对暂存区与工作区差异，确认暂存区 `.gitignore` 为旧版本（缺密钥忽略规则）。
3. 更新 `.gitignore` —— 补充 `node_modules/`、`.claude/`、`.codex/`、`.agents/` 忽略规则；保留 `.env`、`API-key.md`、`dist/`、`.idea/` 等原有规则。
4. `git rm --cached .idea/.gitignore` —— 将误暂存的 IDE 文件移出暂存区（不删除工作区文件）。
5. `git add <项目相关文件>` —— 仅暂存与项目相关的源码、测试、资源与报告文件。
6. `git commit -m "..."` —— 创建项目首个提交。
7. `git remote add origin https://github.com/Bucishuimym/ThatGirl` —— 关联远端仓库。
8. `git push -u origin master` —— 推送至远端。
