## 四、版本规范（Semver）

每次发布必须遵循语义化版本，用 npm version 自动升级并打 tag：

- `npm version patch`：修复 bug（1.0.0 → 1.0.1）
- `npm version minor`：新增功能（1.0.0 → 1.1.0）
- `npm version major`：破坏性更新（1.0.0 → 2.0.0）

发布流程：`npm version <patch|minor|major>` → `npm publish`（prepublishOnly 自动 build + test）。
