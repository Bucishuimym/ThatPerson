1. `git status --short --branch` —— 查看工作区与暂存区状态，确认上期基线干净、列出新增文件
2. `git diff --cached --stat` / `git diff --stat` —— 核对暂存区与工作区差异
3. `npm.cmd test` —— 构建与测试全部通过后准备提交（第 4 期亲验 111/111 全绿）

6. `git push -u origin master` —— 推送至远端

## 二、变更内容（按模块分条）

### 模块一：Bug 修复（P0 发布阻塞）
- `src/cli.ts`：新增 `parseArgs` 全局参数解析——`--version/-V` 输出版本即退出（不再误入对话）、`--help/-h` 打印帮助退出、`--mock` 保留离线语义、`--input-file` 支持（UTF-8 剥 BOM）、未知参数收集提示。
- `src/parser/archive.ts`：P0 归档极性修复——否定前置检测（正向「喜欢」命中前紧邻否定/不确定前缀即拦截，杜绝「不喜欢/不确定…喜欢」双极性）、疑问词过滤（wh-词/疑问语气词/问号结尾不进偏好对象）、不确定性降级（同句「不确定/也许/可能」置信度降「中」并标注待确认）。

### 模块二：智能核心（元认知行为化 + LLM 语义归档）
- `src/cli.ts`：指令-执行-返回通道（S-05）——`/check directory` 与自然语言「检查工作目录/列出目录」经 `detectToolIntent`/`runTool` 真实执行并回传 LLM；TOOL_COMMANDS 白名单，未支持项诚实拒绝。
- `present/behavior.md`：新增「能力自查开关」行为条目（不确定能否执行先自查再回应，禁止「答应 + 虚构动作」）。
- `present/capabilities.md`（新建）：能力清单（技能/CLI 指令/记忆能力/能力边界），经 `loadPresent()` 自动注入 System。
- `src/chat.ts`：`buildSkillsSummary` 生成 `<技能清单>` 摘要层（技能名 + 描述首句 + 触发词，仅 frontmatter 数据，SKILL.md 正文不进 System）；`<临近提醒>` 数据块（未来 14 天倒计时）；渐进式询问指令；`escapeSummaryTags` 摘要输入侧转义（FZ-4b）。
- `src/skill.ts`：`parseFrontmatter` 修复多行 YAML 列表 `trigger_keywords` 解析（出厂技能自动触发生效）；`listSkills` 过滤 `disabledSkills`。
- `src/parser/llm-archive.ts`（新建）：LLM 语义归档（默认关闭，`THATPERSON_LLM_ARCHIVE=true` 才启用）；schema 校验（type/confidence/dialog/insight/tags 全字段，任一条目非法整批拒绝）；`mergeArchives` 规则版兜底；`--mock` 不发网络；Key 优先读 `AAGENTDS_ARCHIVE_API_KEY` 分离。

### 模块三：CLI 生态（内部指令 + 全局指令）
- `src/cli.ts`：内部指令表（S-02）——`/help /history /clear /reset /exit /save /update`，由 CLI 直接执行不送 LLM；`/save` 快照落 `history/sessions/`（不覆盖同名）；`/reset` 清空历史/摘要/近期输入三处。

- `src/skill.ts`：`skills list/enable/disable` 支撑（listSkills 过滤禁用项）。

## 六、影响与注意

- 全局命令由 `thatperson <子命令>` 提供（status/memory/session/config/skills/update/help），无参数才进入持续对话；`--version/-V`、`--help/-h` 输出即退出。
- 对话内 `/` 前缀指令由 CLI 处理（内部指令 > Skill 斜杠 > 工具通道 > 未知提示），不再全部送模型。
- `config.model` 为唯一模型来源（默认 `deepseek-v4-flash`），改模型走 `thatperson config set model <值>`。
- 技能启停持久化到 `config.json` 的 `disabledSkills`，`skills list` 显示启用状态。
- 更新检查 12h 缓存落 `~/.thatperson/.last-update-check`；本地开发（`THATPERSON_DEV=true` 或 `G:\XXFS\` 路径）自动跳过。
- LLM 语义归档默认关闭：需 `THATPERSON_LLM_ARCHIVE=true` 且配置 Key（建议独立 `AAGENTDS_ARCHIVE_API_KEY`）才启用。
- `--input-file <路径>` 可替代管道输入（UTF-8 剥 BOM），规避 Windows 管道中文乱码。
- 发布动作（`npm publish` + `npm unlink` + 真实安装验证）待 BUCISHUI 确认版本 1.1.0 后执行；tarball 含 `__pycache__/*.pyc` 与历史遗留 `dist/index.js`，发布前建议评估清理（待确认）。
